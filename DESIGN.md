# Acuan Desain Aplikasi

Master desain yang berlaku adalah [UI_DESIGN_SYSTEM_GUIDE.md](UI_DESIGN_SYSTEM_GUIDE.md).
Baca dokumen tersebut sebelum merencanakan atau mengubah menu, halaman, fitur, komponen, atau CSS.

Arah desain sudah ditetapkan pengguna: pertahankan tema aplikasi saat ini, GAJIANICH / Emerald Enterprise.
Jangan memilih tema, font, palet, pustaka ikon, atau layout shell baru berdasarkan preferensi agen.
Perubahan identitas visual memerlukan instruksi eksplisit pengguna yang menyebut perubahan tersebut.
Permintaan menambah fitur atau departemen, termasuk GA, bukan izin mengganti desain.

Dokumen per halaman hanya boleh mengatur kebutuhan bisnis dan susunan konten dalam master ini.
Dokumen tersebut tidak boleh mengganti token visual global atau mengesampingkan master.

## Larangan Tombol Refresh Halaman
Dilarang keras menambahkan tombol refresh manual ("Refresh", "Segarkan Data", "Muat Ulang", ikon RefreshCw) di header atau toolbar halaman mana pun. Data harus termuat secara reaktif dan otomatis.
