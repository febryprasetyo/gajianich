# Design Quality & Mobile UX Standards

## Anti-Template & Premium Craft
- Do not ship generic, cookie-cutter templates or unfinished library defaults.
- Maintain consistent design tokens, sleek light/dark aesthetics, subtle blur/glass panels, and refined typography.
- Provide clear visual hierarchy: distinct primary/secondary actions, bold key metrics, and muted metadata labels.

## Mobile-First & Responsive Requirements
- **Viewport adaptation**: Always ensure interfaces look stunning and functional on mobile devices (360px - 430px) as well as desktop (1024px+).
- **Modal dialog architecture**:
  - Backdrop MUST use `fixed inset-0 z-50 flex items-center justify-center p-3 sm:p-4 bg-slate-900/60 backdrop-blur-sm overflow-hidden`.
  - Dialog card MUST use dynamic viewport height: `max-h-[92dvh] sm:max-h-[88vh] flex flex-col overflow-hidden`.
  - Header MUST be pinned at the top (`shrink-0`).
  - Form/content body MUST have dedicated scrolling: `flex-1 min-h-0 overflow-y-auto overscroll-contain`.
  - Action buttons (Cancel/Submit) MUST be in a sticky footer (`shrink-0 border-t`) so they are never pushed off-screen or cut off by browser toolbars.
- **Touch target safety**: All interactive elements (buttons, icons, select options) must have a minimum touch target size of 40x40px (preferably 44x44px).
- **Table responsiveness**: Tables with more than 4 columns must support smooth horizontal scrolling or collapsible card views on small viewports.

## Standard Application UI Design Template (Reference: EmployeeDirectoryPage.tsx)

All dashboard master and transaction pages MUST strictly adhere to this exact visual pattern:

### 1. Page Header
```tsx
<div className="flex flex-col md:flex-row md:items-center justify-between gap-4">
  <div>
    <h1 className="text-2xl font-extrabold text-slate-900 tracking-tight flex items-center gap-2.5">
      <Icon className="w-6 h-6 text-emerald-600" />
      <span>{Page Title}</span>
    </h1>
    <p className="text-xs text-slate-500 mt-1">{Subtitle describing page purpose}</p>
  </div>
  <div className="flex flex-wrap items-center gap-2.5">
    {/* Secondary Action */}
    <button className="px-3.5 py-2.5 bg-white border border-slate-200 hover:bg-slate-50 text-slate-700 rounded-xl text-xs font-medium flex items-center gap-2 shadow-sm transition-all cursor-pointer">
      <Icon className="w-4 h-4 text-emerald-600" /> {Label}
    </button>
    {/* Primary Action */}
    <button className="px-4 py-2.5 bg-emerald-600 hover:bg-emerald-700 text-white rounded-xl text-xs font-bold flex items-center gap-2 shadow-sm transition-all cursor-pointer">
      <Plus className="w-4 h-4" /> {Primary Action}
    </button>
  </div>
</div>
```

### 2. KPI / Summary Stats Cards
```tsx
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4">
  {stats.map(s => (
    <div key={s.label} className="p-4 rounded-2xl flex items-center gap-4 bg-white border border-slate-200 shadow-sm">
      <div className={`w-10 h-10 rounded-xl border flex items-center justify-center ${s.tone}`}>
        {s.icon}
      </div>
      <div>
        <p className="text-[11px] text-slate-400 uppercase tracking-wider font-mono">{s.label}</p>
        <p className="text-xl font-bold text-slate-900 mt-0.5">{s.value}</p>
      </div>
    </div>
  ))}
</div>
```
- Available tones:
  - Emerald: `bg-emerald-50 border-emerald-100 text-emerald-600`
  - Amber: `bg-amber-50 border-amber-100 text-amber-600`
  - Blue: `bg-blue-50 border-blue-100 text-blue-600`
